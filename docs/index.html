Providers

你的邮箱，开箱即用

内置常用服务商预设，也支持任意自定义 IMAP / SMTP。添加向导会真实连接服务器验证凭据，通过后账号立即挂载、后台增量同步。

Gmail QQ 邮箱 163 / 126 Outlook / M365 iCloud 企业微信邮箱 阿里企业邮箱 自定义 IMAP / SMTP

QQ / Gmail / 163 等要求「授权码 / 应用专用密码」而非网页登录密码，向导内有对应指引。

Why ccmail

原生，所以安静

没有 Electron、没有内嵌的网页前端——每一个窗格都是 Go 画出来的原生控件。省下的开销，变成了启动速度和跟手的滚动。

原生控件绘制

侧栏、消息列表、阅读区、写信、设置全部经 mygo/ui 由 Go 绘制，没有页面路由，没有前端构建；HTML 正文单独交给系统 WebView 内嵌渲染。

实时推送

每个账号一条 IMAP IDLE 长连接监听收件箱，新邮件即时到达；服务端不支持 IDLE 时自动降级为定时轮询，连接每 25 分钟自动续期。

安全的正文渲染

HTML 先经 Go 白名单清洗：脚本、iframe、表单与 on* 事件全部剥离；远程图片默认拦截、可一键加载，CID 内联图转为本地 data URL。

富文本写信

加粗、斜体、下划线、列表、链接与粘贴格式，支持附件拖拽和 ⌘ + Enter 发送；回复 / 回复全部 / 转发一步到位，已发送自动归档。

多账号聚合

统一收件箱与星标视图，账号按颜色区分、标题栏一点即切；按 UIDVALIDITY + UIDNEXT 增量同步，信封缓存本地，正文按需拉取。

桌面集成

发件人 + 主题的桌面通知，点击聚焦窗口；托盘菜单、程序化应用图标，浅色 / 深色 / 跟随系统，侧栏可收成图标栏（⌘B）。

Keyboard

手不离键盘

读完一封、归档一封、跳到下一封——收件箱里最常做的动作，都给了单键位。搜索、侧栏、写信也都在指尖。

应用内按 ? 可随时查看完整快捷键列表。

Privacy

隐私是默认，不是选项

没有账号体系，没有埋点。ccmail 只做一件事：把你的邮件送进你的收件箱。

加密存储

邮箱凭据以 AES-256-GCM 加密，密钥由本机 data/secret.key 派生，只存在于你的电脑里，不上传任何服务器。

远程内容默认拦截

HTML 正文先白名单清洗再交给内嵌 WebView：脚本、iframe、表单、事件属性全部剥离；远程图片默认不加载，需要时可一键放行。

无统计、无遥测

不联网上报任何数据，data/ 之外不做任何写入；删掉目录即完全重置，邮件缓存全部留在本机。

Download

下载 ccmail 2.2.0

GitHub Releases 提供 macOS、Windows 与 Linux 安装包；也可以用 Go 直接从源码构建。

macOSApple Silicon & Intel ccmail 2.2.0.dmg 前往下载 Windows10 / 11，需 WebView2 ccmail Setup 2.2.0 amd64.exe 前往下载 Linuxamd64，需 WebKitGTK tar.gz · deb 前往下载
$ git clone https://github.com/CarlOpenLab/ccmail && cd ccmail
$ go build -o ccmail . && ./ccmail # Go 1.27+，直接运行
$ go tool mygo build # 打安装包：dmg / Setup / tar / deb

安装包目前为 ad-hoc 签名：macOS 首次打开需右键「打开」，Windows 可能出现 SmartScreen 提示，确认后即可运行。
